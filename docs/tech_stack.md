# Документация

## Технологический стек

### Backend

* C#
* .NET
* ASP.NET Core

Основной язык и платформа для разработки серверной части приложения.

### Frontend

* Angular
* TypeScript

Основной стек для разработки web-приложения.

### Mobile

* Kotlin

Основной язык для разработки мобильных приложений.

### База данных

* PostgreSQL

Основное хранилище данных приложения.

### Кэш

* Redis

Распределённый кэш для часто используемых данных и временного состояния приложения.

### Обмен сообщениями

* Apache Kafka

Используется для взаимодействия между сервисами и обработки очередей сообщений.

### Gateway / Proxy

* Nginx

Используется как reverse proxy и API gateway.

### Логирование

* Elasticsearch

Используется для централизованного хранения и поиска логов.

### Мониторинг

* Grafana

Используется для сбора и визуализации метрик приложения и инфраструктуры.

### Контейнеризация

* Docker

Используется для контейнеризации приложения и инфраструктурных компонентов.
