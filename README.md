# Garaj

> Система для организации и управления рабочими процессами автосервиса.

## О проекте

Приложение предназначено для автоматизации внутренних процессов автосервиса и организации работы сотрудников.

Основная идея — собрать в одном месте **задачи, сотрудников, этапы выполнения работ и финансовые показатели**, чтобы руководитель и сотрудники могли видеть текущее состояние работы сервиса.

Приложение должно помогать отвечать на простые вопросы:

* Какие работы сейчас выполняются?
* Кто отвечает за конкретную задачу?
* На каком этапе находится работа?
* Сколько работы уже выполнено?
* Сколько заработал автосервис?
* Какая нагрузка приходится на сотрудников разных специализаций?
* Какие задачи ещё не выполнены?

## Основные возможности

### Управление сервисом

Администратор или технический директор сможет контролировать основные показатели работы автосервиса:

* фиксировать выполненные работы;
* учитывать прибыль;
* отслеживать текущие задачи;
* контролировать этапы выполнения работ;
* видеть загрузку сотрудников;
* получать общую картину работы сервиса.

### Управление сотрудниками

Сотрудники автосервиса разделяются по специализациям.

Например:

* 🔧 **Слесари**
* ⚡ **Автоэлектрики**
* 🚘 **Арматурщики**
* и другие специалисты.

Для каждого сотрудника можно будет видеть назначенные ему работы и их текущий статус.

### Задачи

Менеджер сможет создавать и назначать задачи сотрудникам.

Каждая задача содержит необходимую информацию о работе и проходит определённые этапы выполнения.

Например:

```text
Задача
  ↓
Назначена сотруднику
  ↓
В работе
  ↓
Выполнена
  ↓
Закрыта
```

Это позволит видеть не только список задач, но и **реальный прогресс выполнения работ**.

### Оценка выполненных работ

Работы сотрудников могут иметь определённую стоимость или оценку.

По мере выполнения задач формируется информация о проделанной работе.

В дальнейшем это позволит анализировать:

* количество выполненных задач;
* объём выполненной работы;
* вклад отдельных сотрудников;
* эффективность отдельных направлений;
* финансовый результат.

## Общая концепция

Приложение строится вокруг нескольких основных сущностей:

```text
Автосервис
    │
    ├── Сотрудники
    │     ├── Слесари
    │     ├── Электрики
    │     └── Арматурщики
    │
    ├── Работы
    │     └── Задачи
    │           └── Этапы
    │
    └── Финансы
          └── Прибыль
```

Таким образом, работа автосервиса представляется как последовательность процессов:

**работа → задача → сотрудник → этап → результат → деньги**

## Цель проекта

Цель проекта — создать удобную систему, которая позволит перенести повседневную работу автосервиса из разрозненных таблиц, сообщений и устных договорённостей в единую систему.

Вместо того чтобы выяснять:

> «Кто сейчас делает эту машину?»

или

> «Что уже сделали по этой работе?»

информация должна быть доступна непосредственно в приложении.
